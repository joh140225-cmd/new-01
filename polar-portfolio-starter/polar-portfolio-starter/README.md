# 꿈꾸는 폴라 2.0 — Vercel 정적 사이트 시작 파일

## 파일
- index.html: 7개 섹션 콘텐츠
- styles.css: 반응형 디자인
- script.js: 모바일 메뉴와 연도 표시

## GitHub 업로드
압축파일을 해제한 뒤 세 파일(index.html, styles.css, script.js)을 저장소 최상위(root)에 업로드하세요. README.md는 선택 사항입니다.

## Vercel 설정
- Framework Preset: Other
- Root Directory: ./
- Build Command: 비워두기
- Output Directory: 비워두기(기본값)
- Install Command: 비워두기

## 공개 전 확인
- 실제 연락처와 링크 추가
- 소개 및 프로젝트 설명 검토
- 사진을 추가할 때 사용 권한 확인
- 모바일 화면 확인
- 비밀번호/API 키/개인정보 업로드 금지

이 시작 버전은 하나의 HTML 페이지에 7개 섹션이 있으며, 각 섹션은 메뉴에서 이동할 수 있습니다. 독립된 7개 하위 페이지는 후속 확장 단계입니다.
